# LoopLab
Music making software

**LoopLab Studio** is a browser-based music playground. Mix drums, bass, guitar, keys, horns and
percussion from different genres live. Every swap lands on the beat, and the music never stops.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:5173 and press **Space** (or the ▶ button).

## Status
